# Extract fixed effect model matrix columns corresponding to the vcov matrix

Extract fixed effect model matrix columns corresponding to the vcov
matrix

## Usage

``` r
get_fixed_model_matrix(fit, data, is_TMB)
```

## Arguments

- fit:

  Fitted model object

- data:

  Data frame used to fit the model

- is_TMB:

  Logical; whether the model is a glmmTMB object
