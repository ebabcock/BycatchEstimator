# Allocate design estimates to grouping variable not in the designVars

Allocate design estimates to grouping variable not in the designVars

## Usage

``` r
getDesignEstimatesUngroup(logdatval, groupVar, designVars, designstratadf)
```

## Arguments

- logdatval:

  logbook data with effort and sample units

- groupVar:

  grouping variable to allocate estimates to

- designVars:

  design variables used to calculate estimates

- designstratadf:

  data frame of design estimates by designVars
